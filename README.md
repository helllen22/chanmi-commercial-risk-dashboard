# 서울 골목상권 커피·음료 매출 하락 조기경보

서울 골목상권의 매출·거래 흐름을 분석하여 다음 분기 매출 하락 위험이 상대적으로 큰 상권을 조기에 선별하고, 프랜차이즈 본사 슈퍼바이저의 관리 우선순위를 제공하는 프로젝트입니다.

## 1. 프로젝트 목표

- 다음 분기 매출이 전년 동기 대비 10% 이상 하락할 위험이 큰 상권 선별
- 여러 위험신호를 결합한 설명 가능한 위험점수 설계
- 위험 상권 중 매출 영향 규모를 고려한 우선관리 TOP 5 선정
- 위험 상태, 주요 원인과 권장 조치를 대시보드로 제공

## 2. 분석 범위

- 분석 기간: 2021년 1분기~2025년 4분기
- 예측 대상 기간: 다음 분기
- 분석 지역: 서울시 골목상권
- 분석 업종: 커피·음료
- 분석 단위: 분기 × 상권
- 위험 타깃: 다음 분기 매출 YoY가 -10% 이하인 경우

본 분석은 상권 단위 분석이며 개별 프랜차이즈 가맹점의 매출을 예측하지 않습니다.

## 3. 최종 위험지표

최종 선별 지표로 `2차 위험신호지수`를 사용합니다.

```text
2차 위험신호지수
= 매출추세 위험점수 × 50%
+ 거래활동 위험점수 × 30%
+ 하락지속 위험점수 × 20%
```

위험점수는 개별 상권의 하락 확률이 아니라, 같은 시점의 상권 중 상대적으로 위험한 상권을 우선순위화하는 점수입니다.

## 4. 모델 비교 및 최종 성능

2024년 검증 데이터에서 다음 네 가지 방법을 비교했습니다.

- 2차 위험신호지수
- 로지스틱 회귀
- 랜덤 포레스트
- 그래디언트 부스팅

2차 위험신호지수는 검증 데이터에서 ROC-AUC 0.803, 평균정밀도(AP) 0.688로 가장 안정적인 전체 순위 성능을 보였습니다.

2025년 최종 테스트 결과는 다음과 같습니다.

- ROC-AUC: 0.814
- 평균정밀도(AP): 0.766
- 전체 실제 하락률: 42.322%
- 위험점수 상위 25% 실제 하락률: 80.333%
- 상위 25% 리프트: 1.898

위험점수 상위 25%를 우선 관리하면 전체 상권을 무작위로 관리하는 것보다 약 1.9배 효율적으로 실제 하락 상권을 선별할 수 있었습니다.

## 5. 우선관리 TOP 5 선정 기준

1. 최신 분기의 위험점수 계산 가능 상권을 선택합니다.
2. 2차 위험신호지수 상위 25%를 위험 후보군으로 선정합니다.
3. 현재 매출이 전체 상권 중앙값 이상인 상권을 선택합니다.
4. 현재 매출의 10%를 시나리오 타격액으로 계산합니다.
5. 시나리오 타격액이 큰 순서로 TOP 5를 선정합니다.

10% 하락 시나리오 타격액은 예측 손실액이 아닙니다. 모든 후보 상권의 현재 매출이 10% 감소한다고 동일하게 가정했을 때, 매출 영향 규모가 큰 상권을 비교하기 위한 관리 우선순위 참고값입니다.

## 10. 한계 및 개선 방향

- 위험점수는 개별 상권의 하락 확률이나 예상 손실액을 의미하지 않습니다.
- 상권 단위 분석이므로 개별 가맹점의 성과를 직접 예측하지 않습니다.
- 임대료, 경쟁 브랜드, 날씨와 지역 행사 등의 외부 요인이 충분히 반영되지 않았습니다.
- 신규 분기 데이터가 추가될 때마다 위험 기준과 성능을 재검증해야 합니다.
- 향후 개별 점포 데이터가 확보되면 상권 단위와 점포 단위 모델을 분리하여 구축할 수 있습니다.
